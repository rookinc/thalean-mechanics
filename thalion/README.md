# Thalion

A thalion is the primitive computational object of Thalean Mechanics.

A thalion consists of a canonical 60-address space organized as a 5 x 3 x 4 hierarchy.

A thalion possesses a canonical registration.

Representations of that registration are produced by registration interpreters.

The thalion is not its representations.

The primitive object is the thalion.

The bit is an interpreted representation of a canonical registration.
