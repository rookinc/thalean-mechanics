# Extension and Evolution from a Discrete Encounter

This project separates quotient-visible evolution from kernel-valued
extension in an ordered action-carrier encounter.

The visible algebra is E={1,a,b,ab}. Lifted involutions A and B define
H=AB and H inverse=BA. Their visible images agree, while their
difference is the commutator [A,B]. In the finite D16 realization,
[A,B]=H^2 generates the kernel of the visible quotient.

The theorem is algebraic and makes no physical claim.
