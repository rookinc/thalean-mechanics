\section{Executable finite census}

The bundled audit exhausts declared receipt assignments on several connected
base graphs:

\begin{itemize}
\item a tree, with cycle rank zero;
\item directed cycle supports, with cycle rank one;
\item a theta graph, with cycle rank two;
\item a two-triangle bouquet, with cycle rank two.
\end{itemize}

The tested receipt groups include cyclic groups, the Klein four group, the
symmetric group $S_3$, and the dihedral group of order eight. For every
declared assignment, the audit verifies tree normalization, simultaneous
conjugacy classification, generated holonomy subgroup, component count,
component size, connectedness, and the cycle specialization.

The finite census is evidence for the implementation and declared examples.
The theorem for arbitrary finite connected $X$ and finite $R$ follows from
the symbolic proofs in the main text.
