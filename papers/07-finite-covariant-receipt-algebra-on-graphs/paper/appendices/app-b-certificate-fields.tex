\section{Minimum raw-graph certificate fields}

The machine-readable certificate schema accompanies this manuscript. At
minimum, a completed application should contain:

\begin{enumerate}
\item hashes and sizes for the base and lifted graphs;
\item the projection and every fiber;
\item the finite group table and identity element;
\item the permutation realizing each group element on every fiber;
\item one receipt for every oriented base edge;
\item inverse-edge and regular-action failure counts;
\item a reconstruction isomorphism and its failure count;
\item a spanning tree, cotree edges, and fundamental circuit receipts;
\item the holonomy subgroup and its order;
\item predicted and observed component profiles;
\item alternative-root, alternative-tree, and gauge-covariance checks;
\item explicit statements of every unproved physical or orientation claim.
\end{enumerate}

This field list defines the interface between the abstract algebra and a raw
finite graph. Missing fields remain missing premises; they are not supplied by
the classification theorem.
