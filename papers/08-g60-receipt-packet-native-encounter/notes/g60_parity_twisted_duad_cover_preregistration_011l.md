# G60 parity-twisted duad cover preregistration 011l

## Purpose

Packet 011k proved that root stabilizers and ordered-duad stabilizers are
abstractly S3 but are nonconjugate embeddings in the canonical five-point
S5 action.

The ordered-duad stabilizer is mixed parity with orbit profile 1+1+3.
The root stabilizer is all even with orbit profile 2+3 and equals the even
setwise stabilizer of the assigned unordered duad.

This packet preregisters one replacement source action before constructing
it or counting any bridge.

## Declared source action

Let D be an unordered duad of the canonical five-point set and let epsilon
be a binary sheet coordinate.

The proposed twenty-object source is

`D_tilde = {(D, epsilon)}`.

For `g` in the canonical normal subgroup `N`, define

`g.(D,epsilon) = (gD, epsilon + parity(g_bar) mod 2)`,

where `g_bar` is the five-point S5 image of `g`.

This is a parity-twisted double cover of unordered duads. It is not ordinary
endpoint ordering.

## Non-blind prediction

The declared prediction is:

- the source action is transitive on twenty objects;
- a source stabilizer has order 12 in N;
- its five-point image is the all-even S3 setwise stabilizer;
- source and assigned-root stabilizers agree exactly;
- exactly two N-equivariant bridges to the twenty roots exist;
- the bridges are exchanged by global sheet reversal and root inversion;
- one compatible anchored sheet choice selects exactly one bridge;
- choosing one of the two native S5 complements is unnecessary.

The prediction is structural and non-blind. It follows from the stabilizer
embedding identified in 011k, but it is not recorded as a result.

## Boundary

No source action has been constructed or validated. No bridge has been
counted. No anchor ablation has been performed.

This packet does not identify a minimal directional datum, select an
orientation, construct a replacement source A-set, mutate the manuscript,
derive geometry, or make a physical claim.
