# G60 root relative-sign kernel preregistration 013d

## Object under test

The locked `p+n` action supplies two equivariant bridges from the twenty source objects `(unordered_duad, epsilon)` to the twenty orientation roots.

For either bridge, assign each root the binary sign carried by its source `epsilon`. Define the relative-sign kernel on ordered roots by

`K(r,s) = (-1)^(epsilon(r) + epsilon(s))`.

The kernel is invariant under simultaneous global reversal of every sign.

## Frozen predictions

- exactly two bridges;
- twenty rows and twenty distinct roots per bridge;
- ten roots of each sign per bridge;
- equal root sets for both bridges;
- the two signings are exact global complements;
- both bridges induce the same relative-sign kernel;
- 200 same-sign and 200 opposite-sign ordered pairs;
- kernel rank one and trace twenty;
- zero row sum at every root;
- opposite signs on every locked inverse-root pair.
