# G60 full-A orientation character-extension preregistration 011n

## Purpose

Packet 011m constructs a parity-twisted twenty-object action of the
canonical subgroup N and proves that it admits exactly two equivariant
bridges to the twenty orientation roots.

This packet preregisters the two possible extensions of that sheet action
from N to the full group A=Aut(G60).

## Characters

Let p be the parity of the canonical five-point S5 image.

Let n be the quotient character from A to A/N, which is C2.

The restriction of the known N-sheet action is p. Because A/N has order
two, there are two declared extensions:

- alpha_0 = p
- alpha_1 = p+n

The corresponding source action is

`g.(D,epsilon) = (gD, epsilon + alpha(g) mod 2)`.

## Structural distinction

The character p is blind to the full native V4 kernel of the five-point
action. Therefore elements 65 and 124 fix the p-only sheet.

The character p+n detects those residual elements. It predicts that 65 and
124 exchange the two sheets while 0 and 326 fix them, matching the known
root-conjugation kernel Z1.

## Non-blind prediction

Both declared formulas should define valid transitive full-A actions.

The p-only action should admit zero full-A bridges because its pointwise
kernel is V4 rather than Z1.

The p+n action should admit exactly two full-A bridges. They should be the
same two maps frozen in 011m, exchanged by sheet reversal and root
inversion.

Every compatible anchor should select exactly one p+n bridge. Without an
anchor, both bridges should remain valid.

Thus p+n is predicted to be the unique character extension supporting the
full-A root action.

## Boundary

No orientation is selected. No global minimality, geometry, physical
direction, or physical claim is made. The manuscript is not mutated.
