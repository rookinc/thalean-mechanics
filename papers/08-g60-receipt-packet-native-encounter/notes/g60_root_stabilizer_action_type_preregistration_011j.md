# G60 root-stabilizer action-type preregistration 011j

## Question

Packet 011i proved that removing the V4 kernel mismatch does not make ordered
duads and orientation roots equivalent. Packet 011j classifies the remaining
stabilizer mismatch.

## Candidate distinction

The predicted ordered-duad stabilizer is an S3 that fixes two five-point
objects separately, with orbit profile 1+1+3 and mixed parity.

The predicted root stabilizer is another S3 embedding, with orbit profile 2+3
and only even permutations. It is conjectured to equal the even half of an
unordered-duad setwise stabilizer.

If true, the roots are not ordinary ordered pairs. They carry a different
double-cover geometry over the ten unordered duads.

## Boundary

This packet classifies stabilizers only. It does not construct a replacement
source action, select an orientation, identify a minimal datum, alter the
manuscript, or make a physical claim.
