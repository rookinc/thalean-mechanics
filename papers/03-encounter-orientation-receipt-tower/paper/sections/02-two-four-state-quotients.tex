\section{Two four-state quotients}

Define the encounter algebra
\[
E=\{1,a,b,ab\}\cong C_2\times C_2,
\]
where \(a^2=b^2=1\) and \(ab=ba\). Every nonidentity element of
\(E\) has order two.

Define the orientation algebra
\[
O=\langle r\mid r^4=1\rangle\cong C_4.
\]
The elements \(r\) and \(r^3\) have order four.

\begin{proposition}[Nonidentification]
The groups \(E\) and \(O\) have the same cardinality but are not
isomorphic.
\end{proposition}

\begin{proof}
An isomorphism preserves element orders. The order profile of \(E\) is
\(1,2,2,2\), while the order profile of \(O\) is \(1,2,4,4\).
\end{proof}

Consequently, a four-role encounter chart cannot itself supply a
four-step orientation generator. Any relationship between these
objects must pass through additional lifted structure.
