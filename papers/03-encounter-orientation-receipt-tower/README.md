# Encounter-Orientation Receipt Tower

This project proves the compatibility theorem joining the first two
Thalean Mechanics papers.

The visible encounter algebra E is the Klein four group. The visible
orientation algebra O is cyclic of order four. They have the same
cardinality but are not the same group. In the lifted apparatus,

H = AB,
c = [A,B] = H^2,
tau = c^2 = H^4.

The commutator is the extension receipt and its square is the binary
full-return receipt. Nontrivial binary holonomy forces C8, and an
involutive factorization of its generator forces D16.

The theorem is finite and algebraic. It makes no physical claim.
