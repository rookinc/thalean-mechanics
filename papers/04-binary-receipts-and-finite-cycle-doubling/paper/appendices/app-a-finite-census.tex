\section{Finite census witness}

The accompanying audit enumerates every binary voltage assignment for cycle
sizes (3\leq n\leq12). For each (n), it confirms:
\begin{enumerate}
\item there are (2^n) voltage assignments;
\item each holonomy value occurs (2^{n-1}) times;
\item exactly two gauge classes occur;
\item the trivial class has cycle profile ([n,n]);
\item the nontrivial class has cycle profile ([2n]);
\item connectedness is equivalent to nontrivial holonomy;
\item the lifted order is (n) or (2n), respectively.
\end{enumerate}

The finite census checks the implementation and supplies reproducible examples.
The theorem for arbitrary (n) follows from the symbolic gauge and iteration
arguments in Sections 3 and 4.
