\section{Introduction}

A visible system can return to its initial state while a lifted system retains
information about the completed circuit. The smallest possible retained
record is binary: the visible state returns, but a hidden receipt changes
sheet. This paper isolates that mechanism and proves its complete finite
classification.

The input is deliberately spare. We assume a directed visible cycle, a
two-element fiber over each visible state, and a deterministic lifted
successor compatible with the deck exchange. No metric, probability,
continuity, or physical dynamics is required. The result is correspondingly
rigid. One circuit produces either the trivial receipt or the nontrivial
receipt, and these two cases exhaust the gauge-equivalence classes.

The nontrivial class forces cycle doubling. A visible (n)-cycle becomes a
single lifted (2n)-cycle. This statement generalizes the order-four to
order-eight result used in earlier finite action constructions and separates
the theorem from that particular realization. The language of voltage graphs
provides a standard setting for the construction \cite{gross-tucker}, but the
proof below is elementary and explicit.
