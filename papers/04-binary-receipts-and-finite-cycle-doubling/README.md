# Binary Receipts and Finite Cycle Doubling

This project proves a general classification theorem for deterministic
binary lifts of finite directed cycles.

For every visible cycle `C_n`, a deterministic `C_2`-covariant lift is
classified up to fiber-preserving gauge by one binary circuit holonomy.
Trivial holonomy produces two disjoint copies of `C_n`. Nontrivial
holonomy produces one connected cycle `C_{2n}`. Consequently, a
nontrivial binary return receipt uniquely forces cycle doubling.

The result is finite and algebraic. It makes no physical claim.
