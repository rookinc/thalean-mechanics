# Theorem dependency audit

The classification requires:

1. a directed visible cycle `C_n` with `n >= 3`;
2. a finite group `R` acting regularly on each receipt fiber;
3. a deterministic lifted successor covering the visible successor;
4. covariance under the regular `R` action;
5. `R`-equivariant fiber-preserving gauge equivalence.

Covariance forces each lifted edge map to be right multiplication by a
single voltage. Gauge changes the voltage list by a nonabelian coboundary.
The ordered voltage product changes only by conjugation and can be placed on
one edge by gauge normalization. This establishes conjugacy class as a
complete invariant without assuming commutativity.

Cycle length and component count then follow from the orbits of right
multiplication by the holonomy element.
