# Finite Receipt Holonomy and Cycle Multiplication

This project classifies deterministic regular lifts of a finite directed
cycle with an arbitrary finite receipt group.

Let `R` be a finite group and let `h` be the full-circuit receipt. Up to
`R`-equivariant fiber gauge, the lift is classified by the conjugacy class
of `h`. If `h` has order `d`, the lift has `|R|/d` components, each a cycle
of length `n*d`. It is connected exactly when `R` is cyclic and `h`
generates `R`.

Binary cycle doubling is the case `R=C2` and `d=2`.

The theorem is finite and algebraic. It makes no physical claim.
