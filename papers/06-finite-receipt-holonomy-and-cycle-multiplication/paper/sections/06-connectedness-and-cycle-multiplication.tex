\section{Connectedness and cycle multiplication}

\begin{corollary}[Connectedness criterion]
The lifted cover is connected if and only if
\[
\ord(h)=|R|.
\]
Equivalently, it is connected if and only if $R=\langle h\rangle$.
\end{corollary}

A finite group containing an element of order equal to the group order is
cyclic. Therefore a connected regular receipt lift over a single visible
cycle exists only for a cyclic receipt group, with generating holonomy.

This gives the general multiplication law. If $R=C_m$ and $h$ generates
$R$, then $d=m$, the component count is one, and
\[
C_n\longrightarrow C_{nm}.
\]
The visible cycle closes after $n$ steps. The receipt closes after $m$
visible circuits. Complete lifted return therefore occurs after $nm$ steps.

For nongenerating holonomy of order $d<m$, the same local multiplication
occurs inside each component, but the lift separates into $m/d$ identical
cycles of length $nd$.
