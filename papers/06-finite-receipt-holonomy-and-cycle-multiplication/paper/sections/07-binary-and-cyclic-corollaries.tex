\section{Binary and cyclic corollaries}

Take $R=C_2$. There are two holonomy classes.

If $h=e$, then $d=1$, and the cycle profile is
\[
[n,n].
\]
The lift is two disjoint copies of the visible cycle.

If $h\neq e$, then $d=2$, and the cycle profile is
\[
[2n].
\]
The lift is the unique connected doubled cycle $C_{2n}$. This recovers the
binary cycle-doubling theorem.

More generally, for $R=C_m$ and a holonomy of order $d$ dividing $m$, the
profile is
\[
\underbrace{[nd,\ldots,nd]}_{m/d\text{ entries}}.
\]
Thus one cyclic receipt group contains every divisor-controlled return regime:
trivial duplication, intermediate multiplication with several components,
and full connected multiplication by $m$.

Paper 4 is therefore not replaced. It is identified as the smallest
nontrivial connected member of this larger theorem.
