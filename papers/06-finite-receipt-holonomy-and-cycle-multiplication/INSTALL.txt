FINITE RECEIPT HOLONOMY AND CYCLE MULTIPLICATION

This project is source complete. It does not compile LaTeX locally.

1. Run the theorem audit:

   python scripts/audits/audit_finite_receipt_holonomy_cycle_multiplication_theorem_001.py

2. Create and test the source-only Overleaf archive:

   bash scripts/zipit.sh

3. Upload the generated archive from dist/ to Overleaf.

The audit is read-only. The packaging script writes only into dist/.
