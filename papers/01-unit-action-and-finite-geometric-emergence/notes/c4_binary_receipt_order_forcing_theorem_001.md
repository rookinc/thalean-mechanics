# C4 binary-receipt order-forcing theorem

## Result

Let the visible base be the directed four-cycle

\[
W\longrightarrow X\longrightarrow Y\longrightarrow Z
\longrightarrow W.
\]

Attach a binary receipt fiber \(C_2=\{0,1\}\) over each visible
phase. Every deterministic \(C_2\)-covariant local lift is described
by four edge voltages

\[
v_0,v_1,v_2,v_3\in C_2.
\]

Its circuit holonomy is

\[
\omega=v_0+v_1+v_2+v_3\pmod 2.
\]

If \(T\) denotes the lifted successor, then

\[
T^4(i,s)=(i,s+\omega).
\]

If \(\omega=0\), one visible circuit preserves the receipt sheet.
The lift has two connected components, each isomorphic to \(C_4\),
and \(T\) has order four.

If \(\omega=1\), one visible circuit exchanges the receipt sheet.
Consequently \(T^4\neq1\), \(T^8=1\), and the lifted system is one
connected eight-cycle. Thus \(T\) has order eight.

## Gauge classification

There are sixteen binary edge-voltage assignments. Eight have trivial
holonomy and eight have nontrivial holonomy. Vertexwise binary gauge
switching preserves circuit holonomy.

All assignments with trivial holonomy form one gauge class. All
assignments with nontrivial holonomy form one gauge class. Therefore
the connected nontrivial lift is unique up to fiber-preserving gauge
and isomorphism.

The edge on which a representative voltage is placed is not unique.
The lifted isomorphism type is unique.

## Order-forcing statement

The exact implication is

\[
C_4
+
C_2
+
\text{nontrivial circuit receipt}
\quad\Longrightarrow\quad
C_8.
\]

Order eight is therefore not an independent closure assumption after
the following premises have been established:

1. the visible successor has first return after four phases;
2. the receipt fiber is binary;
3. the lift is deterministic and \(C_2\)-covariant;
4. one visible circuit produces the nontrivial receipt.

## Boundary

This theorem does not derive the WXYZ successor cycle from a physical
or native source. It does not independently bind an existing signed
receipt to the binary fiber. It does not prove that a native WXYZ
circuit exchanges that receipt.

Those are representation and provenance gates, not missing algebra.

No electron, gravity, radiation, force, field, energy, momentum, or
spacetime claim is made.

## Keeper

Four visible phases and one nontrivial binary return receipt leave
only the eight-cycle.
