# Parity in the Dihedral Receipt Tower

This project proves the parity law governing the relationship between an
encounter commutator and the binary return receipt of a doubled cycle.

Let `H=AB`, where `A` and `B` are involutions, and suppose `H` has order
`2n`. Then `<A,B>` is the dihedral group of order `4n`, the commutator is
`c=[A,B]=H^2`, and the binary return receipt is `tau=H^n`.

If `n` is even, `tau=c^(n/2)` and the commutator tower reaches the binary
receipt. If `n` is odd, `tau` is independent of `<c>` and
`<H>=<c> x <tau>`. The natural encounter quotient hides `tau` exactly in
the even case.

The theorem is finite and algebraic. It makes no physical claim.
