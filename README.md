# Thalean Mechanics

Thalean Mechanics is a research program into the ontology and mechanics of lawful computation.

Its primitive computational object is the thalion.

The current reference realization of the canonical thalion is the Thalean Graph (G60).

This repository defines what a thalion is before defining what a thalion does.

Boundary

This repository defines computational ontology.

It does not define implementation technology.

Implementation systems (xkernel, B32K, Xaether, G900, manufacturing, blockchain, etc.) are consumers of this theory, not part of the theory itself.
